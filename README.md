# Ayushman Ayurvedic Center

A buildless, responsive website. Deploy the `dist/` directory on any static web host. Open `dist/index.html` directly for a local preview, or serve it with any static HTTP server. No installation or build is required.

## Included
- Semantic HTML, responsive CSS, vanilla JavaScript, and custom inline SVG icons.
- Self-hosted optimized WebP photography originally sourced from Unsplash.
- Lotus intro, reveal animations, parallax, counters, subtle tilt and magnetic effects.
- Reduced-motion support, persistent-on-page motion toggle, focus indicators, skip link, and native disclosure timeline.
- Appointment enquiry validated in the browser, then prepared as a WhatsApp link. It sends nothing automatically and stores no submitted details on the site.
- Map loads only on request. Google Maps and WhatsApp require an external connection.

## Editorial and audit notes
Clinic history, staff information, establishment dates, and service claims are based on the supplied client brief. Photography is illustrative, not actual facility photography. Confirm claims and current staffing with clinic records before public release. The source implements accessibility features but has not received a formal WCAG or government audit. The local browser preview service was unavailable during implementation; responsive browser, screen-reader, contrast, external map, and WhatsApp checks remain part of release QA.

## Main files
- `dist/index.html`: content and structure
- `dist/style.css`: complete styles, responsive rules, print and motion preferences
- `dist/app.js`: menu, animations, form preparation, and map loader
- `dist/assets/`: bundled optimized photography
